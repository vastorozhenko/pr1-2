
# Практична: Інтеграція безпеки в SDLC — покрокові інструкції

## 1) Старт проєкту і репозиторію
1. Створіть порожній репозиторій у Git (GitHub/GitLab).
2. Імпортуйте цей навчальний шаблон.
3. Оберіть модель розробки: **DevSecOps (рекомендовано)** або Agile/Waterfall.
4. Оновіть `docs/requirements-security.md` (п. «Початкові вимоги та ризики»).
5. Зафіксуйте комміт `chore: init security baseline`.

## 2) Аналіз вимог до безпеки
1. Заповніть розділи функціональних/нефункціональних вимог у `docs/requirements-security.md`.
2. Опишіть загрози і цілі безпеки для застосунку (конфіденційність, цілісність, доступність, відповідність).

## 3) Модель загроз і інструменти
1. Опишіть STRIDE-аналіз у `docs/threat-model.md` — додайте принаймні 3 сценарії атак.
2. Заповніть `docs/risk-register.csv` (ймовірність, вплив, пріоритет).
3. Запустіть початковий аналіз вразливостей (наприклад, **Semgrep** локально: `make semgrep`).
4. Додайте висновки до `docs/threat-model.md` («Виявлені ризики/знахідки»).

## 4) Автоматизований SAST у CI
1. Увімкніть вкладку Actions/Pipelines у вашому репозиторії.
2. Переконайтеся, що `.github/workflows/sast.yml` зібрався і згенерував звіти у артефакти.
3. Налаштуйте правила тріажу: створюйте задачі в Issue Tracker (GitHub Issues) за знайденими уразливостями.
4. Опишіть процедуру у `docs/sast-process.md`.

## 5) DAST (OWASP ZAP baseline)
1. Запустіть локально `docker-compose up -d app` або `make up`.
2. Запустіть `make zap` або дочекайтеся CI-воркфлоу `dast.yml`.
3. Перегляньте HTML-звіт у `reports/zap/` та додайте короткі висновки в `docs/dast-process.md`.

## 6) Підсумковий аудит безпеки
1. Звірте виконання вимог у `docs/audit-report.md`.
2. Опишіть ролі: Owner, Security Champion, Dev, QA, DevOps у процесі.
3. Додайте рекомендації з покращення (backlog і ітераційний план).

## Додатково
- Використайте **pip-audit** / **Trivy** для перевірки залежностей/контейнера.
- Додайте GitHub CodeQL (опційно).
- Налаштуйте secret scanning.

**Оцінювання**: зіставте з рубрикою у завданні, додайте посилання на артефакти CI (SAST/DAST).
